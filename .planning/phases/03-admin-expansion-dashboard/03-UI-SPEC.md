# Phase 3 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|

| Font | Space Grotesk (display), Plus Jakarta Sans (body) |

---

## Visual Hierarchy

- **Primary focal point:** Jobs table status + artist columns and the primary bulk action button.
- **Secondary focus:** filter/search controls that refine operational scope quickly.
- **Tertiary focus:** per-row actions (retry/details) and supporting metadata.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Badge/inline icon gaps |
| sm | 8px | Compact control spacing |
| md | 16px | Default field/cell spacing |
| lg | 24px | Section internal padding |
| xl | 32px | Header/body block separation |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level breathing room |

Exceptions: checkbox/select hit areas must remain at least 44x44px on touch layouts.

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(240, 20%, 4%)` | Page/background surfaces (`$bg-primary`) |
| Secondary (30%) | `hsl(240, 14%, 10%)` | Table container, filter bar, row hover containers (`$bg-surface`) |
| Accent (10%) | `hsl(258, 80%, 62%)` | Active status chips, selected-row checkboxes, primary bulk action, focused filter controls |
| Destructive | `hsl(0, 72%, 58%)` | Failed state badges, destructive/critical error emphasis only |

Accent reserved for: primary “Queue Selected Artists” button, selected checkbox states, active filter state, and “queued/running” emphasis badges only.

---

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Queue Selected Artists |
| Empty state heading | No expansion jobs yet |
| Empty state body | Select artists and queue expansion to start tracking job status here. |
| Error state | We couldn’t load expansion jobs. Refresh the dashboard. If this persists, retry in a moment and check worker/DB health. |
| Destructive confirmation | Retry Failed Job: Requeue this failed expansion job now? |

Additional empty-filter state:
- Heading: No jobs match these filters
- Body: Adjust status or search text to see matching jobs.
